# -Study-of-cloud-botnet-recognition-techniques-and-implementation-of-an-LLM-assisted-triage-pipeline-
Tesi triennale su anomaly detection non supervisionata (One-Class SVM, Autoencoder, iForest, LOF) su telemetria eBPF (dataset BETH) e analisi comparativa di una pipeline di triage per cloud security basata su LLM (Gemini) rispetto a una configurazione LLM-only.
